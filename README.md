# 微信 AI 助手（ClawBot）

把一个 AI 助手装进你的微信。装完之后，你在微信里发消息，它就会回你——
能聊天、能查东西、能帮你写代码改文件，还能画图（画图要单独开通，见下文）。

---

## 怎么安装

### 最简单：复制一行，粘进去回车

**Mac** —— 打开「终端」App（按 `Command + 空格`，输入「终端」回车），粘这条：

```bash
curl -fsSL https://raw.githubusercontent.com/liujingyangself/clawbot-wechat/main/get.sh | bash
```

**Windows** —— 在开始菜单搜索「PowerShell」打开，粘这条：

```powershell
irm https://raw.githubusercontent.com/liujingyangself/clawbot-wechat/main/get.ps1 | iex
```

就这一条。它会自动下载、安装、然后在需要你帮忙的时候弹窗提醒。

### 在中国大陆的话

**只有这台电脑需要能连外网，手机不用。** 你的手机微信照常用国内网络就行。

需要连外网的是电脑上这几件事：下载安装包、用 Google 的 AI、Antigravity 登录。
微信消息本身走的是腾讯的国内服务器，不需要也不会绕到国外。

安装前**先打开你的代理软件**（Clash、v2rayN 这类），确认浏览器能打开 google.com，
然后再跑安装命令。安装程序会**自动找到你的代理并配置好**，不用你填端口。

> **为什么不能只开「系统代理」就完事**
>
> 开了系统代理，浏览器能上 Google，看起来一切正常。但助手的后台程序
> （Node.js）**不读系统代理设置**，照样连不上，而且报的错完全看不出是网络问题。
>
> 所以安装程序会专门探测你的代理端口，把它写进助手自己的配置里。
> 这一步是自动的，你不用管——知道有这回事就行。

如果那条一行安装命令本身就下载不动（GitHub 在国内也经常连不上），
在命令前面加上代理再跑（把 7890 换成你软件里显示的端口）：

```bash
export https_proxy=http://127.0.0.1:7890 http_proxy=http://127.0.0.1:7890
curl -fsSL https://raw.githubusercontent.com/liujingyangself/clawbot-wechat/main/get.sh | bash
```

Windows 的 PowerShell 里是：

```powershell
$env:HTTPS_PROXY='http://127.0.0.1:7890'; $env:HTTP_PROXY=$env:HTTPS_PROXY
irm https://raw.githubusercontent.com/liujingyangself/clawbot-wechat/main/get.ps1 | iex
```

### 或者：让 AI 帮你装

如果你电脑上有 Antigravity、Claude、Cursor 这类 AI 助手，直接跟它说：

> 帮我安装 https://github.com/liujingyangself/clawbot-wechat

它会自己读懂怎么装。

### 或者：下载压缩包双击

[下载 ZIP](https://github.com/liujingyangself/clawbot-wechat/archive/refs/heads/main.zip)，

## 安装过程中你需要配合三次

需要你配合的时候，安装器会**自己弹出一个新窗口**（显示二维码、或者 Google 登录界面）。
你在那个窗口里操作完，它会自动关闭并继续装剩下的。

所以你可以直接把这个项目丢给 AI 助手让它装，你只管扫码和点授权。

| 顺序 | 你要做什么 | 多久 | 重要性 |
|---|---|---|---|
| 1 | **用 Google 账号登录 Antigravity**（会打开浏览器） | 2 分钟 | ⚠️ **最关键，别跳过** |
| 2 | 去一个网页复制一串密钥贴回来（以 `AIza` 或 `AQ.` 开头） | 2 分钟 | 备用通道 |
| 3 | 用**手机微信扫二维码** | 半分钟 | 必需 |

全程大约 10–20 分钟，大部分时间是电脑自己在下载东西，你可以去干别的。

### 第 1 步为什么最关键

助手有两条通道，额度差得非常远：

| 通道 | 额度 | 作用 |
|---|---|---|
| **Antigravity**（第 1 步） | 用你的 Google 账号，额度大得多 | 日常干活靠它 |
| Gemini 密钥（第 2 步） | 免费档**每天只有二十来次** | 只是兜底 |

**跳过第 1 步的话，助手每天回二十来条消息就会停**，然后报一串看不懂的英文错误
（`429 RESOURCE_EXHAUSTED`）。所以第 1 步出现时，请一定耐心做完。

Antigravity 那个登录界面是键盘操作的，照着提示走：

1. 选配色 → 直接按**回车**
2. 条款页 → 建议按**空格**取消勾选「分享数据」，再按**回车**
3. 登录 → 选「用浏览器登录」，在弹出的浏览器里登录 Google
4. 看到最下面出现 `>` 输入框 = 成功了
5. 输入 `/quit` 再回车，回到安装程序

安装器**会检查这一步有没有成功**，没成功会问你要不要再试一次。

> 💡 **如果在 Windows 默认控制台里按回车或方向键无反应**：这是 Windows 传统控制台（conhost）对全屏 TUI 交互界面的兼容性问题。按 `Ctrl + C` 退出即可，日常微信聊天完全不受影响；也可使用现代的 Windows Terminal 运行。详见 [docs/常见问题.md](docs/常见问题.md)。

## ⚠️ 装之前先知道这件事

**电脑必须一直开着，助手才会回消息。**

它的工作方式是在你电脑上挂一个后台服务，一直连着微信的服务器等消息。
电脑关机、睡眠、断网，这个服务就停了，助手也就不回话了。

- **合上笔记本盖子 = 睡眠 = 助手停工**
- 手机上**跑不了**——手机负责跟助手说话，助手本身住在电脑里
- 不需要买服务器，但你那台电脑就相当于服务器

所以比较合适的用法是：**装在一台不怎么关机的电脑上**（台式机，或者一直插着电的笔记本）。

### 怎么让电脑不睡觉

**Mac**：系统设置 → 锁定屏幕 → 「接通电源时，如果显示器关闭则防止自动进入睡眠」打开。
笔记本还要注意别合盖（合盖必睡）。

**Windows**：设置 → 系统 → 电源和电池 → 屏幕和睡眠 → 把「接通电源时，经过以下时间后使设备进入睡眠状态」设为「从不」。

## 装完怎么用

> 📖 **完整的使用说明在 [docs/使用说明.md](docs/使用说明.md)** ——
> 怎么聊天、有哪些命令、怎么让它干写代码改文件这类大活，都在里面。
> 下面是最常用的几条。

在微信里找到那个助手的会话，直接说话就行：

```
今天东京天气怎么样
把桌面上那个 report.txt 的前三行念给我听
帮我在 ~/Desktop/test 下建个 Python 脚本，打印 1 到 100 的质数
```

**常用的几条**（在微信里直接发）：

| 发这个 | 作用 |
|---|---|
| `/help` | 问它能干什么 |
| `/new` | 开一个全新对话，换话题时用 |
| `停` | 让它中断正在干的事（不用加斜杠） |
| `用 agy 帮我把桌面那个脚本改成……` | 交给 Antigravity 干重活 |
| `画一只戴帽子的柴犬` | 画图（需先开通，见下文） |

## 如果助手说额度用完了

看到类似这样的消息：

> Google Generative AI API error (429): You exceeded your current quota...

意思是**当天的免费次数用光了**，不是坏了。按这个顺序查：

1. **Antigravity 登录了吗？** 没登录的话每天只有二十来次。补登录：打开终端 / PowerShell
   敲 `agy`，照提示登录一次
2. 等 24 小时额度会重置
3. 想要更多：去 https://aistudio.google.com/apikey 开通计费（按量付费）

## 关于画图

画图**需要付费**，因为 Google 对图像生成没有免费额度（约 1 元人民币一张）。

- 安装时会问你要不要开通，**选「跳过」完全不影响其他功能**
- 以后想加上：安装程序会把文件放在你的用户文件夹下的 `clawbot-wechat` 里，
  进去 `scripts` 文件夹，Mac 双击 `添加绘画-Mac.command`，Windows 双击 `添加绘画-Windows.bat`

## 这东西安全吗

几条你应该知道的：

1. **只有你能用它。** 陌生人给你发消息，助手不会理，除非你明确批准。
2. **它改不了重要文件。** 默认只允许它在你的「文稿」和「桌面」里干活，碰不到系统设置、
   密码、SSH 密钥这些。
3. **群里它不说话。** 默认在群聊里完全沉默，避免打扰别人。
4. **别让它帮你群发。** 这违反微信的使用条款，可能导致封号。
