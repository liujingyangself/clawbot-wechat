# 常见问题

遇到问题先看这里。每一条都写了「你会看到什么」和「怎么办」。

---

## 安装的时候

### Mac：双击提示「无法打开，因为无法验证开发者」

**怎么办**：右键点那个文件 → 选「打开」→ 在弹出的框里再点一次「打开」。
只需要做这一次，以后双击就行。

### Windows：提示「此应用无法在你的电脑上运行」或者一闪而过

**怎么办**：右键点 `安装-Windows.bat` → 选「以管理员身份运行」。
如果还是一闪而过，说明 PowerShell 被策略挡了，在开始菜单搜 PowerShell，
右键以管理员打开，粘这条进去回车：

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

然后重新双击安装。

### 卡在「正在下载安装」很久不动

正常的。OpenClaw 要下载几百兆，网速慢的话十几分钟也可能。
**只要窗口没报错就别关**。真的超过 30 分钟没动静，关掉重新双击一次。

### 提示连不上 Google

你需要能访问 Google 的网络。如果你在中国大陆，先打开你平时用的代理软件，
确认浏览器能打开 google.com，再重新安装。

### 密钥粘贴了三次都说不对

常见原因：

1. **复制漏了**：那串密钥很长（将近 40 个字符），确认是从 `AIza` 开头到最后全选复制的
2. **复制到了别的东西**：网页上有好几处能点复制，要点密钥本身旁边的复制按钮
3. **key 刚创建还没生效**：等一分钟再试

重新打开 https://aistudio.google.com/apikey ，删掉旧的重新创建一个。

## 装完之后

### 在微信里发消息，助手不回

按顺序查：

**第一步：服务在跑吗？**

Mac 打开「终端」，Windows 打开 PowerShell，粘这条：

```
openclaw gateway status
```

看到 `running` 就是好的。没看到就粘这条重启：

```
openclaw gateway restart
```

**第二步：微信连着吗？**

```
openclaw channels status
```

要看到 `openclaw-weixin` 而且后面是 `running`。
如果没有，重新跑一次安装程序，它会让你重新扫码。

**第三步：是不是没配对？**

助手默认**只理会你批准过的人**。如果是别人给它发消息，它会不理。
看看待批准的有谁：

```
openclaw pairing list openclaw-weixin
```

要批准就：

```
openclaw pairing approve openclaw-weixin 那串码
```

### 开着 Clash，浏览器能上 Google，但助手说连不上 AI 服务

**这是最常见的一个坑，不是你的错。**

代理软件的「系统代理」模式只对浏览器这类程序有效。助手的后台程序是 Node.js 写的，
它**不读系统代理设置**，所以照样连不上。

安装程序本来会自动探测你的代理端口并配置好。如果还是不行，通常是这几种情况：

1. **代理软件重启后端口变了。** 重新运行一次安装程序，它会重新探测。
2. **你的软件只开了 socks5，没开 HTTP 代理。** 去它的设置里把「HTTP 代理」
   或「混合端口」打开——助手只能用 HTTP 代理，用不了 socks5。
3. **想手动确认配的是哪个端口**，在终端 / PowerShell 里粘：

```
openclaw config get proxy.proxyUrl
```

改成别的端口：

```
openclaw config set proxy.proxyUrl http://127.0.0.1:你的端口
openclaw gateway install --force
openclaw gateway restart
```

**还有个办法**：把代理软件切到「TUN 模式」或者「虚拟网卡模式」。这个模式接管整台
电脑的所有流量（包括 Node.js），配好之后什么都不用管。缺点是开起来稍微麻烦点。

### 微信消息会不会也被绕到国外去

不会。代理软件是按规则分流的，微信、淘宝这些国内网站在所有主流规则里都是直连，
只有 Google 这类才走代理。所以配了代理不会让你的微信变慢，也不会有额外风险。

### 之前好好的，突然不回消息了

**最常见的原因：电脑睡着了或者关机了。**

这个助手住在你电脑里，电脑不醒着它就不工作。检查一下：

1. 电脑是不是休眠了？（笔记本合盖就会）
2. 网断了吗？
3. 都正常的话，打开终端 / PowerShell 粘这条看看服务还在不在：

```
openclaw gateway status
```

没看到 `running` 就粘这条重启：

```
openclaw gateway restart
```

**电脑关着的时候别人发的消息，开机后能补上吗？**

不一定。微信服务器那边有个续传机制，重新连上会从上次的位置继续，
但腾讯没有公开说明消息会暂存多久。短时间（几分钟到几小时）通常能收到，
关了好几天就不好说了。**别把它当成留言机用。**

### 助手回得很慢

第一次回话慢是正常的（要加载）。之后一般几秒。
如果一直很慢，可能是免费额度用完了，等一会儿再试。

### 助手说「我没有被允许做这个」

这是故意的保护。它默认只能在**桌面**和**文稿（文档）**里干活，
碰不到系统设置、密码、SSH 密钥这些。

如果你确实需要它动别的地方，让懂技术的朋友改
`~/.gemini/antigravity-cli/settings.json` 里的 `permissions`。

### 群里它不说话

也是故意的。默认在群聊里完全沉默，避免打扰别人、也避免被群里的人骗。

### 画图说没开通

画图要单独开，而且**要花钱**（一张约 1 元）。
Mac 双击 `scripts/添加绘画-Mac.command`，Windows 双击 `scripts\添加绘画-Windows.bat`。

### 画图开通了但报错

一般是计费还没生效，等 5-10 分钟。还不行的话去
https://console.cloud.google.com/billing 确认账单账号已经关联到你创建密钥的那个项目。

## 日志在哪

出问题时把这个文件发给帮你装的人：

- **Mac**：`~/Library/Logs/clawbot-wechat-install.log`
- **Windows**：`%LOCALAPPDATA%\clawbot-wechat\install.log`

Mac 想快速打开这个文件夹，在终端粘：

```
open ~/Library/Logs
```

## 怎么卸载干净

**Mac**，在终端里依次粘这几条：

```
openclaw gateway stop
openclaw gateway uninstall
rm -rf ~/.openclaw
rm -rf ~/.gemini/antigravity-cli
rm -f ~/.local/bin/agy
```

**Windows**，在 PowerShell 里：

```
openclaw gateway stop
openclaw gateway uninstall
Remove-Item -Recurse -Force "$env:USERPROFILE\.openclaw"
Remove-Item -Recurse -Force "$env:USERPROFILE\.gemini\antigravity-cli"
```

微信那边不用做什么——卸载后助手就不再登录你的微信了。

另外记得去 https://aistudio.google.com/apikey 把那把密钥删掉。
