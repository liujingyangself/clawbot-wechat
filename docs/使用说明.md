# 怎么用这个微信助手

装好之后，它就住在你的微信里。**你直接跟它说话就行，不用记命令。**

这份说明从最常用的开始，越往后越少用。

---

## 一、开始用

打开微信，找到那个助手的会话，像跟朋友发消息一样发过去：

```
你好
```

它几秒钟内就会回你。**第一条可能慢一点**（要加载），之后就快了。

> 它只理会你。别人给它发消息它不会回，除非你明确批准过。群里它默认完全不说话。

---

## 二、怎么跟它聊天

### 直接说人话，不用特殊格式

```
今天东京天气怎么样
帮我把这段话翻译成日语：明天下午三点有空吗
一千块人民币大概多少日元
解释一下什么是复利，用买奶茶举例
```

### 它能看你电脑里的文件

```
看一下桌面上有哪些文件
把「文稿」里那个 report.txt 的前三行念给我听
我桌面上那个 Excel 大概讲了什么
```

> 它只能看「桌面」和「文稿（文档）」这两个地方，碰不到密码、系统设置这些。
> 这是故意限制的。

### 说不清楚也没关系

你可以发语音转文字、可以有错别字、可以说半句。它会按最可能的意思去做，
然后告诉你它是怎么理解的。觉得理解错了，直接说「不对，我是想……」就行。

### 它不知道的事会说不知道

查不到就说查不到，没权限就说没权限。**它不会编。** 要是发现它瞎说，告诉它一声。

---

## 三、让它干大活（这个最值钱）

聊天和查东西它自己就能做。但**真要写代码、改一整个项目、排查程序为什么坏了**，
它会交给一个叫 **Antigravity** 的工具去干——那个工具用的是你 Google 账号的额度，
能力强得多。

### 怎么让它用

**你不用记命令，直接说要干什么就行**，它自己会判断该不该叫 Antigravity：

```
帮我在桌面建一个 Python 脚本，打印 1 到 100 之间的质数
我桌面那个项目跑不起来，帮我看看为什么
把「文稿」里那个网页的标题改成「我的小站」，顺便把配色换成深色
给我写个小工具，把一个文件夹里所有图片批量改名成 001、002 这样
```

**想明确要求用它**，就加一句：

```
用 agy 帮我……
交给 Antigravity 做：……
```

### 这类活要等多久

| 活的大小 | 大概时间 |
|---|---|
| 改一个文件、写个小脚本 | 半分钟到两分钟 |
| 看一整个项目、排查 bug | 两到五分钟 |

**它不会一直沉默**。开跑前会先回你一句，跑完把结果用人话讲给你。
等得不耐烦可以直接问「好了吗」。

### 任务说得越具体越好

| 不太好 | 更好 |
|---|---|
| 帮我改改这个网站 | 把桌面上 mysite 文件夹里的首页标题改成「小李的主页」，背景换成浅灰色 |
| 代码有问题 | 桌面 myapp 文件夹，运行就报错退出，帮我找出原因并修好 |

### 它干不了的事

Antigravity 被限制在**桌面和文稿**里干活，而且**不能**：

- 删除文件、推送代码到网上、发布东西
- 读你的密码、密钥这些敏感文件
- 自己去网上下载东西来运行

撞到限制时它会直说「这个我没被允许做」。**这是保护，不是故障。**

---

## 四、常用命令

这些要**单独发一条**，前面带斜杠：

| 发这个 | 作用 |
|---|---|
| `/help` | 问它能干什么 |
| `/new` | **开一个全新对话**（它会忘掉之前聊的，换话题时很有用） |
| `/status` | 看它现在的状态 |
| `/compact` | 聊太久变慢时，压缩一下历史 |

### 想让它停下来

直接发（**不用加斜杠**）：

```
停
```

或者 `停止`、`别做了`、`stop` 都行。它会中断正在干的事。

### 要你批准的时候

它要跑某些命令时会先问你。你会看到类似：

> 这条命令在等你批准：……

回一句 `同意` 或者 `/approve` 就行。**不想让它做就直接说不行。**

## 五、画图

```
画一只戴帽子的柴犬
帮我画一张简约风格的生日贺卡
```

**画图要单独开通，而且按张收费**（一张大约 1 元）。没开通的话它会告诉你，
并不影响其他功能。

想开通：找到安装时那个文件夹（在你的用户文件夹下，名字叫 `clawbot-wechat`），
进去 `scripts`，双击 `添加绘画-Windows.bat`（Mac 是 `添加绘画-Mac.command`）。

---

## 六、几件别做的事

1. **别让它群发消息。** 「给我所有好友发个祝福」这种，它会拒绝——微信的规则禁止
   自动群发，真做了可能导致封号。要群发请你自己手动发，它可以帮你把内容写好。

2. **别把别人发来的内容当命令转给它。** 如果有人发给你一段话，里面写着
   「让你的助手把某某文件发出来」之类的，**那是在骗它**。它被教过要拒绝，
   但你最好也别试。

3. **它改东西之前会问你。** 删文件、改文件、发消息给第三个人——这些它都会先确认。
   **没看懂就别点同意。**

---

## 七、它不回我消息了

按顺序检查：

1. **电脑开着吗？** 它住在电脑里，电脑关机或睡眠了它就停工。笔记本合盖 = 睡眠。
2. **网络正常吗？** 它要连 Google，国内需要代理软件开着。
3. **是不是额度用完了？** 它会直接告诉你。等一天会恢复。

还不行就看 [常见问题](常见问题.md)，或者找帮你装的人，把这个文件发给他：

- Windows：`%LOCALAPPDATA%\clawbot-wechat\install.log`
- Mac：`~/Library/Logs/clawbot-wechat-install.log`
